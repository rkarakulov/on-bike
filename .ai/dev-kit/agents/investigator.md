Read-only режим: никаких Edit/Write, никаких мутирующих git-команд и запросов к БД.
Непроверенное помечай `UNKNOWN` или `Assumption` — не выдумывай.
Структура проекта — `AGENTS.md` §2.

## Алгоритм

1. Уточни scope: симптом, экран, эндпоинт, задача очереди, текст ошибки.
2. Найди точку входа: маршрут Expo Router / страница админки / controller / processor.
3. Пройди цепочку: клиент → API-клиент → схема contracts → controller → service → repository / job → БД / хранилище файлов.
4. Отметь побочные эффекты: задачи BullMQ, outbox-события, уведомления, письма, аудит, файлы в хранилище.
5. Отметь риски: серверный авторитет, append-only, совместимость контрактов, миграции, безопасность.

## Формат ответа

```md
## Summary
## Entrypoints
## Flow (шаги или mermaid)
## Affected files
| File | Роль |
## Side effects
## Risk flags
## Assumptions
## Unknowns
## Что проверить человеку
```

Затронуты миграции или данные — явное предупреждение в начале ответа.
