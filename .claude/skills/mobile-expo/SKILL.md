# mobile-expo — процесс для apps/mobile

Правила — `.claude/rules/mobile.md`. Сначала план экрана, потом код.

## 0. Рамки MVP (проверь первым)

Нет записи GPS, фоновой геолокации, BLE, push, Strava/Garmin API, биометрического входа.
Задача требует что-то из этого — стоп, это продуктовое решение и ADR, а не реализация.

## 1. План экрана

- **Маршрут** в `app/` (Expo Router): путь, параметры, guard авторизации, гостевой режим.
- **Deep link / universal link:** какой из 5 типов объектов открывает экран; возврат к объекту после регистрации.
- **Данные:** запросы `@on-bike/api-client`; статусы обработки — `refetchInterval`, не сокеты.
- **Состояния:** по AGENTS.md §4.12 через `AsyncContent` и `SkeletonGroup` + `Skeleton*`: какой скелетон повторяет раскладку экрана, что видно сразу.
- **Дизайн-система:** из каких компонентов `src/components/ui` собран экран; чего не хватает — какой компонент/токен добавляем в систему (с тестом и примером на `/ui-kit`), а не стиль по месту.
- **Строки** — `@on-bike/i18n` (формальное «вы»), **стили** — семантика `useTheme()` + `textStyle()` и компоненты `src/components/ui` (светлая Jersey Aura, тёмная Night Ride); примитивы и hex — нельзя.

## 2. Типовые возможности

- **Карта:** MapLibre — линия маршрута, старт, коридор, трек пользователя, подсветка вне коридора; тема карты следует теме приложения.
- **Файлы:** системный picker; pre-check расширения, размера и пустого файла (`@on-bike/tracks`);
  resumable upload с процентом, отменой и паузой без сети; очередь загрузок переживает перезапуск, очищается при выходе.
- **Шеринг:** системный share sheet и копирование ссылки; карточку рендерит сервер.
- **Геолокация:** только foreground, pre-permission экран, «Не сейчас», баннер со ссылкой в настройки ОС при отказе.
- **Удаление аккаунта:** нативный alert с последствиями.

## 3. Доступность и движение

`accessibilityLabel` / `accessibilityRole` / `accessibilityState`; `accessibilityActions` вместо
единственного drag-жеста; масштабирование шрифта; reduce motion — упрощённая анимация
(вспышка достижения без мерцания).

## 4. Нативное

Только через config plugins Expo (CNG): `ios/` и `android/` не коммитим. Новая нативная зависимость —
проверить совместимость с SDK 58 и pnpm-монорепо, отметить в pr.md.

## 5. Проверка

Jest (jest-expo) + Testing Library: состояния, навигация по deep link, формы.
`pnpm --filter @on-bike/mobile typecheck`, `pnpm check`. Ручная проверка на симуляторе —
в pr.md как `NOT VERIFIED`, если не делалась.
