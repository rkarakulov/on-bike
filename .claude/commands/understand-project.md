# /understand-project

Фокус: $ARGUMENTS

1. Прочитай `AGENTS.md` (§2 структура, §4 инварианты) и `.claude/rules/*` затронутых путей.

## Выход (brief, не решение)

- **Зона:** приложение / модуль / слой.
- **Файлы и модули**, которые реально затронет задача.
- **Reuse points:** схемы contracts, сервисы, утилиты tracks, компоненты, токены.
- **Правила в игре:** какие `.claude/rules/*` критичны.
- **Инварианты и ловушки:** серверный авторитет, append-only, совместимость контрактов, миграции, безопасность.
- **Команды проверки** для зоны.
