# Тесты

- Новое поведение — с тестом. Багфикс — сначала тест, который падает без исправления.
- Пакеты, API и admin — Vitest; приложение — Jest (jest-expo) + Testing Library.
- API: unit для сервисов, интеграционные для репозиториев на реальной БД (стенд `@rkarakulov/test-kit`),
  HTTP — через стенд (`createApiHarness`). Моки БД для запросов к ней запрещены — они врут.
- Тест проверяет поведение, а не реализацию. Тавтологии (тест повторяет код) — дефект.
- Без `.only`, `.skip` без ссылки на задачу, без `sleep` — ждать условие.
- Время в тестах фиксировано (fake timers / инъекция clock), таймзона — явно.
