# Тесты

- Новое поведение — с тестом. Багфикс — сначала тест, который падает без исправления.
- Пакеты и web — Vitest; mobile — Jest (jest-expo) + Testing Library; e2e web — Playwright; mobile e2e — Maestro.
- API: unit для сервисов, интеграционные для репозиториев и PostGIS-запросов на реальной БД,
  e2e HTTP через supertest. Моки БД для геозапросов запрещены — они врут.
- Обработка треков (`packages/tracks`, коридор, кластеры) — фикстуры реальных FIT/GPX/TCX файлов
  в `__fixtures__/`, включая битые, пустые, без timestamp, вне коридора.
- Тест проверяет поведение, а не реализацию. Тавтологии (тест повторяет код) — дефект.
- Без `.only`, `.skip` без ссылки на задачу, без `sleep` — ждать условие.
- Время в тестах фиксировано (fake timers / инъекция clock), таймзона — явно.
