# on-bike — веб: панель «Протокол» и лендинг (дополняет `web.md`)

Процесс — скил `app-dev-kit:web-ui`: для админки — как есть; для Astro-лендинга (до F5) его UI-план применяется
временно и напрямую, без перенаправления в `mobile-expo` (лендинг ещё не часть универсального приложения).

## admin — панель «Протокол» (тема `panel`)

- Desktop 1440, только светлая тема, плотные таблицы (TanStack Table): сортировка, фильтры, вкладки кластеров,
  фиксированная шапка.
- Доступ по роли (организатор / модератор / админ); без роли — экран «Нет доступа».
- Формы — react-hook-form + zod; данные — `@on-bike/api-client`.
- Деструктивные и необратимые действия (исключение трека, решение спора, пересчёт, публикация протокола) — модалка
  с обязательной причиной; причина уходит в append-only аудит на сервере.
- Чек-лист публикации протокола блокирует кнопку и объясняет почему.
- Флаги правдоподобия видны только команде платформы и не блокируют публикацию.
- Биометрия (пульс, мощность, FTP, вес) — только в разборе спора (графики HR/мощности по дистанции).

## landing — гостевые страницы (Astro SSR, до F5)

- SSR-страница на каждый тип ссылки (заезд, маршрут, календарь, результат, карточка); данные — серверный запрос
  к API; состояния: недоступно, карточка отозвана, гонка отменена.
- OG-мета и картинка 1200×630, `apple-itunes-app` (iOS Smart App Banner), «Открыть в приложении» — custom scheme.
- Публичное удаление аккаунта: только e-mail, нейтральный ответ, подтверждение по ссылке, действие — POST по кнопке.
- Минимум клиентского JS: острова только там, где нужна интерактивность.
- Оформление — `designSystemCss({ theme: 'light', darkTheme: 'dark' })` из `@on-bike/design-tokens`; hex — нельзя.
- Строки — только ключи `@on-bike/i18n` (формальное «вы»); состояния данных — AGENTS.md §4.12, загрузка — `.skeleton`.
- Доступность: семантические элементы, видимый фокус, контраст, клавиатурная навигация.

## Проверка

`pnpm --filter @on-bike/admin build` / `pnpm --filter @on-bike/landing build` и `pnpm check`; Playwright —
для ключевых сценариев (когда появится).
