# Web — apps/admin (Vite + React) и apps/landing (Astro)

Процесс: скил `.claude/skills/web-ui/SKILL.md`.

## admin — панель «Протокол»

- Desktop 1440, только светлая тема, плотные таблицы.
- Доступ по роли (организатор / модератор / админ); без роли — экран «Нет доступа».
- Данные — `@on-bike/api-client` (TanStack Query), таблицы — TanStack Table, формы — react-hook-form + zod.
- Деструктивные и необратимые действия (исключение трека, решение спора, пересчёт, публикация
  протокола) — модалка с обязательной причиной; причина уходит в append-only аудит.
- Биометрия (пульс, мощность, FTP, вес) показывается только в разборе спора.

## landing — гостевые страницы

- Astro SSR: страница объекта по ссылке (заезд, маршрут, календарь, результат, карточка),
  публичное удаление аккаунта, OG-мета 1200×630.
- Минимум клиентского JS; острова только там, где нужна интерактивность.
- «Открыть в приложении» — custom scheme; iOS Smart App Banner.
- Удаление аккаунта: только e-mail, нейтральный ответ, подтверждение по ссылке, действие — POST по кнопке.

## Общее

- Строки — `@on-bike/i18n`. Оформление — CSS-переменные и классы `.t-*` из `@on-bike/design-tokens`
  (admin — тема `protocol`, landing — `light` + `dark`); hex и копии значений в CSS приложений — нельзя.
- Дизайн-система — единственный источник оформления (AGENTS.md §4.11): нового значения нет в пакете —
  добавь токен/роль в `@on-bike/design-tokens`, а не стиль по месту.
- Состояния данных — строго по AGENTS.md §4.12; загрузка — класс `.skeleton` из пакета.
- Доступность: семантические элементы, фокус, контраст, клавиатурная навигация.
