# Контракты — packages/contracts

- Zod-схемы здесь — единственный источник правды API. Типы выводятся `z.infer`, не дублируются.
- Схема описывает форму данных, а не бизнес-правила сервера (кластеры, места, правдоподобие — только сервер).
- Структура: `src/<context>/<entity>.schema.ts`, публичный экспорт — `src/index.ts`.
- Enum-ы и коды ошибок — `as const` + `z.enum`; клиенты не хардкодят строки статусов.
- Изменения обратно совместимы: новое поле — optional; удаление/переименование — через новую версию
  эндпоинта. Старые мобильные версии в сторах ещё живы.
- Никаких импортов из `apps/*`, NestJS, React, React Native — пакет чистый TS + zod.
- `api-client` генерируется/строится поверх contracts; ручной fetch в приложениях — нет.
- Любая правка — тест на схему (валидный/невалидный вход) + `pnpm typecheck` по всем потребителям.
