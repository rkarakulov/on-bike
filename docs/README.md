# Документация on-bike

| Раздел | Что внутри | Когда читать |
|---|---|---|
| [`product/`](product/README.md) | PRD, epics и стори, архитектурный спайн (инварианты AD-xx), прототипы | продуктовое поведение, acceptance |
| [`architecture/`](architecture/README.md) | текущая архитектура системы: контейнеры, модули, потоки данных | placement, интеграции между модулями |
| [`adr/`](adr/README.md) | принятые архитектурные решения | почему так, а не иначе |
| [`tasks/`](tasks/README.md) | артефакты задач: task.md, findings.md, pr.md | продолжение задачи, история решений |
| [`runbooks/`](runbooks/README.md) | эксплуатация: деплой, бэкапы, инциденты | дежурство, восстановление |
| [`proposal-stack-architecture.md`](proposal-stack-architecture.md) | исходное предложение по стеку (основа ADR-0001) | исторический контекст |

Правило: агент читает 1–4 релевантных документа, а не всю папку. Нет документа — фиксирует gap, не выдумывает.
