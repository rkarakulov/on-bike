# 0004. База app-foundation: пакеты, шаблон и плагин для новых проектов

- Статус: Accepted
- Дата: 2026-10-22
- Дизайн: [`docs/tasks/2026-10-22-app-foundation/design.md`](../tasks/2026-10-22-app-foundation/design.md)

## Контекст

Стек (ADR-0001), универсальное приложение (ADR-0003), дизайн-система, инфраструктура API и AI-цикл
разработки в on-bike почти не зависят от домена. Следующие проекты автора нужны на той же основе.
Копирование даёт расходящиеся базы: исправление в одном проекте не доходит до других. Сейчас доменного
кода мало — выделение дешевле всего.

## Решение

Отдельный приватный репозиторий `rkarakulov/app-foundation` с тремя видами поставки:

1. **Пакеты `@rkarakulov/*`** (GitHub Packages, changesets): `config`, `design-tokens`, `ui`, `i18n-core`,
   `contracts-core`, `api-client-core`, `api-kit`, `test-kit`. Проект подключает их зависимостями и
   обновляет сменой версий (Renovate).
2. **Шаблон copier** — то, что обязано жить в репозитории проекта: каркас монорепо, CI, docker-compose,
   оболочки приложений, AGENTS.md-скелет, `.claude/settings.json` и правила, мосты Codex.
   Обновление — `copier update` (трёхстороннее слияние).
3. **Плагин Claude Code `app-dev-kit`** из маркетплейса в том же репо: команды цикла `/develop-task`,
   агенты, общие скилы стека, хуки.

Бренд (палитры, шрифты, дополнительные темы) и тексты продукта остаются в проекте; база получает их
параметрами. Локализация — часть базы: несколько языков, множественное число, форматирование через `Intl`.

on-bike — первый потребитель. Identity переносится в базу позже, после слайсов 2–3 онбординга.

## Альтернативы

- **Только шаблон-копия.** Быстро, но обновления базы в проекты не доходят.
- **Только пакеты.** CI, файловые маршруты Expo Router и AGENTS.md пакетом не подключить.
- **git submodule / subtree.** Плохо работают с pnpm-воркспейсом и версиями, обновления непрозрачны.

## Последствия

- Изменения базы — отдельный репозиторий, релиз и обновление в проектах; правка «на месте» в on-bike
  для общего кода больше не допускается.
- Нужны токен GitHub Packages локально и в CI, Python-инструмент copier (`uv`/`pipx`).
- Проверка возраста версий pnpm получает исключение только для `@rkarakulov/*`.
- Пересмотреть, если второй проект не появится в течение полугода: тогда база — лишний слой.
